Verifica la firma

Cada entrega trae el header {{ signatureHeader }}: t=…,v1=…. Calcula HMAC-SHA256(secreto, t + "." + cuerpo) sobre el cuerpo crudo, compáralo en tiempo constante con v1 y rechaza timestamps con más de 5 minutos. Responde 2xx para confirmar; si no, reintentamos con backoff exponencial hasta 6 veces.
